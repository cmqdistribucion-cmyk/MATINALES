# Attendance Timer Hub

una pagina web , donde tiene 2 funciones tomar asistencia  la asistencia se toma con si o no(seleccion), tomar asistencia debe tener un sector administrativo para cargar la nomina y gaurdarlo  y un cronometro debe tener campo para el titulo de la capacitacion y la descripcion(opcional) , con un boton para iniciarlo y uno para finalizarlo.el cronometros debe poder ver en pantalla completa letras grande para que el publico puede ver nomalmente que el tiemepo esta correindo. otro panel para historial  donde figura todas las capacitacion fecha hora y los asistentes, debe tener un boton para descargar el historial en un excel y puede filtrar por fecha tambien .
